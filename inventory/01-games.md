## 技术与核验依据

### 鼠哥游戏厅 / SHUGE GAMES

- **技术：** HTML/CSS/JavaScript
- **价值：** 15 款网页游戏的统一游玩入口，适合证明完整产品入口、交互设计与作品矩阵能力。
- **依据/边界：** GitHub 已有公开仓库，含 15 个 games 子目录。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-game/)

### Canvas Racing

- **技术：** Canvas / JavaScript / Node.js
- **价值：** 从街机赛车切入可测试物理引擎；渲染和物理分离、固定步长和 AI 驾驶架构是主要技术资产。
- **依据/边界：** README：Phase 3 已完成，Phase 4 AI 模块开发中，不等于完整竞速规则已交付。
- **公开入口：** 暂未公开

### APEX DRIVE — Coastline Rivals

- **技术：** Three.js / Vite / JavaScript
- **价值：** Three.js 3D 赛车，具备车辆动力学、漂移、氮气和赛道 AI，可作为视觉效果与游戏手感演示候选。
- **依据/边界：** README：固定步长物理、AI、计圈、HUD；2026-10-09 驾驶方向修正。
- **公开入口：** 暂未公开

### APEX COAST

- **技术：** Unity 6 / C# / URP
- **价值：** Unity 独立赛车工程，覆盖 WheelCollider 车辆系统、多车辆 AI、长赛道与构建验证，训练引擎级游戏开发能力。
- **依据/边界：** Docs/STATUS.md：M2 3108.868m 赛道与 6 车测试；美术音效与 UI 尚未完成验收。
- **公开入口：** 暂未公开

### Mouse House

- **技术：** Godot / Blender / GDScript
- **价值：** 以老鼠视角进行室内潜行、猫鼠追逐和环境互动，有鲜明的玩法身份和 3D 场景潜力。
- **依据/边界：** README 与本地 Godot 工程存在；未在本次执行完整游玩验收。
- **公开入口：** 暂未公开

### Project Strike

- **技术：** Unity 6 / C#
- **价值：** Unity 战术射击与 AI 对抗工程，体现 FPS 控制、射击反馈、战斗 HUD 与模块化关卡迭代。
- **依据/边界：** Docs/STATUS.md：Playtest03 已整合游戏绑定 HUD；不宣称完成 5v5 正式版。
- **公开入口：** 暂未公开

### Project Seed / 文明种子

- **技术：** 像素世界 / Agent-based simulation
- **价值：** 以独立个体行动、知识传承和关系网络解释文明涌现；其真正价值是可追踪的因果模拟，而非预编写历史事件。
- **依据/边界：** README 标注 Pre-production / 核心设计验证阶段。
- **公开入口：** 暂未公开

### 余烬邮差 / Ember Postman

- **技术：** Godot 4 / GDScript
- **价值：** 离线 Godot 单人冒险作品，重点在关卡、Boss、叙事结局和完成一款有边界的游戏。
- **依据/边界：** README：25 房间、4 Boss、2 结局是目标，不代表全部已做完。
- **公开入口：** 暂未公开

### 光核围城 / Lumen Siege

- **技术：** HTML5 Canvas / JavaScript
- **价值：** 可独立游玩的像素俯视角动作生存游戏；短局循环和即时反馈适合快速试玩。
- **依据/边界：** pixel-game/README.md；也是游戏厅 15 款之一，不重复计算成独立仓库。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-game/games/lumen-siege/)
