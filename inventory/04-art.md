## 技术与核验依据

### SHUGE GALAXY / 鼠哥星系

- **技术：** Canvas 2D / JavaScript
- **价值：** 把分散的游戏、学习工具和互动艺术串成可探索的像素风作品门户，降低作品传播门槛。
- **依据/边界：** 公开仓库与 GitHub Pages，README 记录地图、跃迁和终端操作。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-galaxy/)

### Neural Garden / 意识花园

- **技术：** Three.js / Blender
- **价值：** 将记忆、生命与意识抽象为交互式空间雕塑，兼具概念表达、实时 Three.js 与 Blender 程序化建模。
- **依据/边界：** 项目说明记录单文件展品、Blender 179 对象与渲染资料；远端 gallery 已核验 index.html。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-galaxy/art/neural-garden/)

### 雨夜便利店 / Rainy Convenience Diorama

- **技术：** Blender / GLB / Web Viewer
- **价值：** 微缩场景建模与三渲二夜景叙事，兼具环境叙事、建模完整性和可旋转交互展示。
- **依据/边界：** STATUS.md：Blender 验收通过，559 meshes、6690 vertices，已导出 GLB 和查看器。
- **公开入口：** 暂未公开

### Voxel Crystal / 体素晶体

- **技术：** Three.js / WebGL / esbuild
- **价值：** 将程序化晶格与生长/崩解运动结合成零安装可观赏的实时 WebGL 装置。
- **依据/边界：** README.md 记载单 HTML 构建与 37 条断言；远端 gallery 存在 index.html。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-galaxy/art/voxel-webgl/)

### 山河为证 / 长征互动叙事

- **技术：** HTML5 / JavaScript / Motion
- **价值：** 历史叙事、交互动画与网页传播的完整组合，是区别于游戏和工具的文化传播作品。
- **依据/边界：** README：2026-10-11 静态公开版本上线；公开页面是互动技术样章，不等于完整投稿。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/shanhe-preview/)

### Orrery / 行星仪

- **技术：** Canvas / JavaScript
- **价值：** 利用可视化机械/轨道语言表达太阳系，适合展示实时图形叙事与信息美术。
- **依据/边界：** 项目 index.html 标题和齿轮驱动太阳系说明，归属于星系艺术回廊。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-galaxy/art/orrery/)

### Chladni / 声场

- **技术：** HTML / CSS / JavaScript
- **价值：** 以板振动与沙粒节线为创作语言，将声学现象做成可交互视觉艺术。
- **依据/边界：** index.html：艺术回廊 №07，频率改变沙粒节线。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-galaxy/art/chladni/)

- **价值：** 围绕环形回廊组织 16 个展项，突出叙事化导航与作品整体品牌的连贯感。
- **依据/边界：** index.html 文案记载 16 件作品；公开总艺术入口属于 SHUGE GALAXY。
- **公开入口：** [试玩/浏览](https://ndshuge.github.io/ndshuge-galaxy/art/)
