# 价值评估与作品优先级

> 更新时间：2026-10-12。根据本机项目文档、GitHub 既有公开入口和实际文件结构进行初筛。优先级是策展建议，不是客观性能评分，也不代表作品已通过验收。

## 如何衡量“有价值”

| 维度 | 观察的问题 | 对用户的实际意义 |
| :--- | :--- | :--- |
| 展示价值 | 30–90 秒能否理解与体验？ | 作品集、面试、分享和观众留存 |
| 技术深度 | 是否有可解释的工程/物理/数值架构？ | 游戏开发、科学计算、系统设计能力 |
| 可信程度 | 有多少测试记录、局限说明与真实运行证据？ | 提高结论可信度，防止“演示即完成” |
| 长期效用 | 能否自己持续用、或者持续积累课程/数据？ | 真正解决问题，而非作品数量堆砌 |

## A：优先展示或继续投入的旗舰

- **公开且可直接给人看**：SHUGE GALAXY、SHUGE GAMES、Math Universe / Chaos、Neural Garden、SHUGE ACADEMY、《山河为证》公开样章。
- **本机强验证、具备深化潜力**：Physics Frontier Lab V0.4、EvoWorld V0.4；两者的科学与体验证据相对完整，但本图鉴没有替它们公开源码。
- **值得做下一轮观众试测**：APEX DRIVE（手感/画面）、Mouse House（游戏性）、AI 学院（真实学习效果）、小芽 OPC（日常留存）。
- **工程能力证明**：Mice Hole（已有公开 Beta 代码）；FactGuard（证据链与可审计性，正式平台验收仍需完成）。
- **视觉作品**：雨夜便利店（GLB 与 Blender 场景已在本机生成，适合做可公开的轻量展示版）。

## B：有特色的第二梯队

Canvas Racing（纯物理架构）、APEX COAST（Unity 车辆与赛道测试）、Project Strike（战术 FPS）、Project Seed（文明涌现设计）、Lumen Siege（可迅速试玩）、Gravity Garden（物理沙盒）、Voxel Crystal、Orrery、Chladni、Art Arcade、Project Lab、Classnote。

这些并非低质量：有些技术难度高但体验尚未收口，有些很好玩却是现有大型展厅/游戏厅的一部分。B 表示**下一轮精修前先把 A 做好**。

## C：继续保留但暂不主推

- **Ember Postman**：有明确游戏范围，目前处于开发中；等完整玩法与关卡证据后再推。
- **Silicon Lab**：教学路线有潜力，但记录仍在第 1 章第 1 节，未验收。

## 最值得兑现的 5 个增量

1. 为赛车建立明确区分的展示路线：Canvas Racing（物理教学）/ APEX DRIVE（浏览器 3D 可玩）/ APEX COAST（Unity 完整赛道项目）。禁止把三者混成一部作品。
2. 为 Math Universe 的 Chaos / Lorenz 单独补一页易懂的讲解：微小初值差异 → 轨道发散 → 不能把“混沌”写成“完全随机”。
3. 让 PFL 与 EvoWorld 输出观众可以复现的参数、实验结论、限制和 60 秒演示；先做公开安全审查再决定是否上线。
4. 给视觉类作品添加经权属核验的截图、移动端体验和创作过程，避免只有项目名称。
5. 让 AI 学院、FactGuard 和 OPC 的**规则系统 / 真正 LLM / 平台验收 / 真人试测**状态始终分开标注。

## 重要边界

“技术展示价值高”不等于“商业估值高”或“可以直接投稿”。科研计算要核对模型的假设与验证；使用第三方图像、音乐、代码和模型前要核对再分发许可；未公开的本地工程不应为了凑仓库数量而直接推送。
