**口径：** 阶段依托 2026-10-12 实际读取的本机工程文件及既有 GitHub 地址。运行或科学测试数字来自原工程的测试记录，未在本次重新完成全量验证。“暂无公开链接”并不是程序不存在；“公开展示”也不代表商业发行。分级是作品集策展选择，不是收入/市场估值。
