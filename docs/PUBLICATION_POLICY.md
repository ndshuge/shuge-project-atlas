## 阶段词汇

| 标记 | 含义 |
| --- | --- |
| 公开展示 | 在已有公开仓库或 Pages 中找到对应发布入口。 |
| 公开样章 | 只有明确范围内的一段正式对外展示。 |
| 公开仓库 | GitHub 上存在，但本次不推断在线服务或完整产品验收。 |
| 本地验收 | 本机工程文档保存过验收结论；不代表本图鉴复测。 |
| 本地可用 / 本地原型 | 找到本机工作文件、程序/入口，但未声称完整产品。 |
| 持续开发 | 工程或子系统在推进；离用户目标还有距离。 |
| 前期设计 / 早期探索 | 研究、课程路线或核心设计验证。 |

**子作品**：一个已经收入游戏厅/艺术展厅/数学宇宙的独立关卡或展项，不能再次计作全新独立产品。

## 公开安全准则

只公开人工筛选的文字索引与链接。下列项目类别默认不复制到本仓库：

- 未审计的本机源码、Git 历史、原始提交记录、实验测试集、私有数据、课堂及个人信息。
- API Key、OAuth Token、服务配置、日志、开发机截图、账号数据、依赖缓存及大体积构建物。
- 第三方素材及许可尚未明确允许再分发的音乐/图片/模型。
- 比赛资料、待提交成果或有独立提交/署名/版权要求的原始文件。

每个源项目都保留原仓库和原路径。未来需要新增源代码仓库，应先做依赖/许可证/隐私/提交历史扫描，再使用独立仓库发布。这里不做无授权的“全盘镜像”。

## 条目维护

正式交互网页由 `data/projects.json` 维护 **23 个精选项目**；网页与原有 `categories/*.md` 对应。额外的 `inventory/` 是单独整理的 **30 条扩展盘点**（含五个嵌套子作品），不是站点 JSON 的另一版本，也不是 30 个独立仓库。更新前应核对原工程证据并人工同步相应文档。

现有无需依赖的基础检查：`node --check app.js`；`node -e "const x=require('./data/projects.json'); if(!Array.isArray(x.projects)) process.exit(1); console.log(x.projects.length)"`。公开前还应人工确认所有外链、素材授权与隐私。
