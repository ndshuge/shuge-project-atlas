# 作品价值整理原则

这是一份 **用于作品展示、技术成长和下一步投入选择的定性整理**，不是给项目定价。

## 四个评价维度
1. **实际可展示**：是否有已上线网页、可运行软件、录屏或经核验的构建结果？
2. **技术含量**：算法、架构、数值验证、交互与工程复杂度是否有可解释证据？
3. **表达与独特性**：新观众能否快速理解亮点，是否形成可辨认的视觉或交互体验？
4. **长期用途**：对学习、求职作品集、科普、创作、比赛或后续产品开发的持续价值。

## 策展等级
- **重点展示 (featured)**：有明确价值与具体证据，适合放在作品集首屏；不保证都已上线。
- **值得展示 (strong)**：技术或体验亮点鲜明，但通常还需要试玩、实测或发布收口。
- **探索阶段 (incubating)**：理念值得保留，验证尚早；应低成本做可测原型。

各项是**编辑判断**，不采用伪精确的分数，也不宣称商业价值金额。科学实验里的教学模型与数值求解严格区分；游戏开发计划与正式交付严格区分。

## 面向不同目的
- **投递作品集 / 面试**：优先展示实机和可复现工程，如 Physics Frontier Lab、EvoWorld、赛车模拟、Mice Hole。
- **吸引一般观众**：优先网页即开即玩，如 SHUGE GAMES、SHUGE GALAXY、山河为证、数学宇宙。
- **校内教育与竞赛**：优先 AI 学院、鼠哥学院、FactGuard、OPC；真实用户试测结果需单独验证。
- **长期研究探索**：Project Seed、复杂系统与 AI 相关实验值得保留，但不应夸大成熟度。

**下次整理时**，逐项目复核当前 STATUS/README、最新构建、公开链接、测试收据、素材许可和对外介绍。评估结果随证据更新，不按项目热度机械提升。
