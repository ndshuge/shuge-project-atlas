## 阅读方式

- **已公开 / 公开预览**：已有公开地址；不等于所有功能、源码或授权素材都完整公开。
- **本机已验收 / 本机已交付 / 本机可运行**：证据来自工程文档、测试或本机运行入口；本仓库**不假装已有在线 Demo**。
- **开发中 / 前期验证**：保留真实进度及未完成的部分，避免把愿景写成已交付。
- **重点展示、具有潜力、探索阶段** 是主观作品集策展级别，**不是商业估值、投资建议、市场价格或客观测评分数**。

评估框架见 [价值整理方法](docs/VALUATION.md)，核验记录见 [来源与边界](docs/AUDIT.md)。

本仓库是 **作品总索引与展示页**，不是将所有项目的原始源码合并成 monorepo。已公开项目保持各自仓库；未公开项目暂时只有文字卡片，**未上传代码、密钥、私有竞赛测试数据、人物信息或不明确授权的第三方素材**。
